# GDGOC Kickoff Event :: Website Challenge

Welcome to the **GDGOC Web Team Challenge!**

Your task is to build an HTML webpage showcasing the GDG on Campus (GDGOC) Kickoff Event at COMSATS Attock Campus. The goal is to practice HTML structure, hyperlinks, forms, and semantic elements while creating an informative and organized website.

## Website Requirements

Your webpage must include the following sections:

### 1. Navigation Bar

* GDGOC name or logo.
* Navigation links: Home, About, Highlights, Teams, and Contact.
* Links should navigate to the appropriate sections.

### 2. Hero Section

* Heading: **GDGOC Kickoff Event**
* A short introduction to the event.
* The provided group photograph or another suitable banner.
* An “Explore Highlights” hyperlink.

### 3. About GDGOC

* Introduce GDGOC and its purpose.
* Explain how students can learn, collaborate, and grow through the community.

### 4. Event Highlights

* Include at least three highlights from the kickoff event.
* Use headings, paragraphs, and lists to organize the content.

### 5. Event Gallery

* Include the provided group photograph.
* Add an appropriate image description using the `alt` attribute.
* You may use the same photograph in more than one section, but avoid unnecessary repetition.

### 6. GDGOC Teams

Introduce the following teams with a short description of each:

* Web Team
* App Team
* Media Team
* PR Team
* AI/ML Team
* Management Team
* Women in Tech Team

### 7. Join the Community Form

Create a form containing:

* Full Name
* Email Address
* Department
* Semester
* Team of Interest (dropdown)
* Submit button

### 8. Useful Hyperlinks

* Include at least three working hyperlinks.
* Add internal navigation links to different sections.
* Include relevant external links, such as official Google Developer resources or GDGOC social media.

### 9. Contact and Footer

* Include relevant official social media or contact links.
* Mention GDGOC and COMSATS Attock Campus.
* Add a “Back to Top” hyperlink.

## 🛠️ Technical Requirements

* Use HTML5.
* Use semantic tags such as `header`, `nav`, `main`, `section`, `form`, and `footer`.
* Use proper heading hierarchy.
* Associate form labels with their corresponding inputs.
* Use suitable input types and `required` attributes where appropriate.
* Add meaningful `alt` text to images.
* Keep your code readable and properly indented.

## Repository Structure

Organize your project as follows:

```text
gdgoc-kickoff-website/
├── README.md
├── index.html
└── assets/
    └── group-photo.jpeg
    ├── kickoff-banner.jpeg
    ├── gdgoc-logo.png

```

The provided group photo should be saved inside the `assets` folder. If you use a different filename, update the image path in your HTML.

## Submission Instructions

1. Fork the official challenge repository to your GitHub account.
2. Clone your fork to your computer.
3. Create your webpage in `index.html`.
4. Add the provided photograph to the `assets` folder.
5. Commit and push your changes to your fork.
6. Submit your public GitHub repository link through the designated submission method.


## Important Notes

* Use the event photograph provided with the challenge.
* Do not invent event details; use only confirmed information.
* You may use placeholders for details that have not been confirmed.
* The registration form is for demonstration only and will not store responses unless connected to a working backend or approved form service.
